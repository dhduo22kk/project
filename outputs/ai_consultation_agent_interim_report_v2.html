기획 배경 : WHY - HOW - WHAT

WHY

기존 ML 추천, 왜 상담사가 사용하지 않는가?

  • • 추천 결과: 상품명 + 고정 문구 → 맥락 없음
  • • "왜 이 고객에게 이 상품인지" 근거 부재
  • • 콜 전 참고 불가 → 사실상 미사용
  • ※ 기존 AutoGluon 배치는 유지 — 이 프로젝트는 보완·연동
HOW

이종 데이터 통합으로 맥락을 주입

  • • 통화 녹취 STT → 고객 발화 맥락 직접 참조
  • • 보장 GAP 자동 탐지 → 누락 담보 명시
  • • 유사 성공 콜 RAG → 캠페인 패턴 반영
  • • Oracle → DuckDB 일배치 → 온디맨드 즉시 조회
WHAT

상담사가 실제로 쓸 수 있는 형태로 출력

  • • ① DuckDB 현황 즉시(<1초) → ② LLM 스크립트 스트리밍
  • • 스크립트 각도: 담보 보완 / 설계 팔로업 / 신상품 자동 선택
  • • 투트랙: 상담사 스크립트 / 관리자 캠페인 Excel
  • • 이노스 레거시에 Gradio API 주입 방식 연동
기존 ML 추천시스템 (AutoGluon) 대비 핵심 개선 포인트
구분 기존 ML 추천시스템 AI 상담 에이전트 (이 프로젝트)
추천 근거 유사 고객 가입 이력만 (ML 점수) 가입 이력 + 담보 GAP + 과거 통화 맥락 + 캠페인 패턴
출력 형태 상품명 + 고정 텍스트 왜 이 상품인지 근거 + 어떻게 말할지 스크립트
상담 활용 맥락 없어 사실상 미사용 콜 전 즉시 활용 가능한 형태로 출력

단순 통계 추천에서 벗어나 통화이력, 보장 GAP, RAG 기반 과거 발화 맥락을 고려한 이유와 화법 제시로 실전 추천력을 혁신합니다.

캠페인 대상 정밀화

갱신 가능 대상 및 30일 내 과다 접촉 고객 자동 배제 기능을 탑재하여 금융 피로도를 감소시키고 불필요한 마케팅 리소스를 통제합니다.

전사 DB 통합관리

분산 저장되었던 통화 녹취, 설명 문서, 고객 정보를 고속 DuckDB 파이프라인으로 유기적으로 연결해 마케팅 원스톱 활용 기반을 마련합니다.

이노스 연계 및 고도화

기존 레거시 화면 레이아웃의 구조적 수정 없이, 고속 Gradio API 인터페이스 주입 방식으로 원활한 UI 연속성을 보장하고 시스템을 고도화합니다.

고객유출 없는 폐쇄망

외부 클라우드/API 통신을 100% 차단하고 사내 온프레미스 GPU 서버 내에서 로컬 LLM을 학습 및 서빙하여 철저한 정보 보안 규범을 충족합니다.
