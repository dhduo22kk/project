왜 만들었나?
기존 ML 추천 — 상담사가 안 쓴다
AutoGluon 기반 추천 결과는 상품명 + 고정 텍스트. 왜 이 상품인지 설명이 없어 현장에서 사실상 미활용.
녹취 5,000건 — 노하우 창고가 잠겨 있다
고능률 상담사의 성공 콜 패턴이 WAV 파일로 쌓여있지만 텍스트 분석·재활용 없이 방치.
캠페인 대상 추출 — 담당자 수작업 SQL
기획자가 매번 Oracle SQL을 직접 작성해 리스트 생성. 캠페인마다 반복 작업, 오류·지연 발생.
분산된 영업 데이터를 AI로 연결 — 상담사·기획자 모두의 도구
